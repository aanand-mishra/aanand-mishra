# Aanand Mishra

Backend/AI Developer at [Prixa](https://inmark.ai) in Kathmandu, Nepal.

I build LLM features, ML evaluation and production Python APIs. Since July 2026 I have worked on inmark.ai, an influencer-marketing platform. My work there covers creator matching, usage billing for AI calls, and contracts.

### What I work on at Prixa

- A nightly OpenAI job that tags each creator with topics, with a cache so no text is sent twice.
- The evaluation harness for a LightGBM fake-follower model, with gated releases.
- Creator matching that scores content, audience and engagement per platform, ranked in SQL.
- Usage billing that converts the USD cost of AI calls into credits at the daily Nepal Rastra Bank rate.
- Contract PDF rendering in idempotent Celery tasks with retries.
- OpenTelemetry tracing, Prometheus metrics and Grafana alerts for the Docker services.
